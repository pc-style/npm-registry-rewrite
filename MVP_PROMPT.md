Build an MVP for an agent-first npm registry trust layer. Use Bun only. Start from the included Theo project brief. Use these stack choices unless the brief reveals a strong reason to adjust: hosted-shaped local registry, Bun CLI, local directory store, and a `RegistryStore` abstraction so storage can later move to a hosted backend. No local server required. Optimize for fastest demo while keeping architecture close to the final product. Core flow: inspect a package before install/exec, fetch npm metadata/tarballs, show identity, size, maintainers, publish/change signals, scripts, dependency risk summary, and a clear allow/deny decision. Cache verdicts locally, support JSON reports, and include a demo flow for reviewing then allowing a package.
